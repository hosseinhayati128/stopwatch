# Create 3 Dark Mode Acanthus Floating Overlay Clock Concepts

## Objective
Create exactly 3 high-quality dark mode concepts for the Acanthus floating overlay clock only.

Do not redesign:
- Controller
- Settings
- Records
- Analytics
- Dialogs
- other themes

## Figma file
Use this read-only file:

https://www.figma.com/design/q1GhB2cTVZiVWhbajEGT4K/StopWatch?node-id=13-6&t=zBkEwoSPfi2Eitki-1

Do not modify existing designs.

## Product structure

The floating overlay must contain:

```
Timer value
Project name below timer
```

Optional:
- REC indicator
- subtle active state

Do not add:
- project header above timer
- permanent status labels
- mode labels
- shortcut labels
- timer lists

Hover state:

Show a separate compact toolbar below the overlay:

- Close
- Pause or Resume
- Reset

The toolbar must be separate from the timer surface.

## Dark Acanthus direction

Create a dark interpretation of Acanthus:

- charcoal / near-black surfaces
- deep olive or forest tones
- antique gold details
- muted sage accents
- warm ivory text

Style:

- elegant
- classical
- premium
- calm
- practical

Avoid:

- fantasy style
- wedding invitation style
- game UI
- dense floral patterns
- excessive decoration
- neon colors

Use restrained:
- thin gold rules
- small acanthus details
- subtle botanical geometry

## Typography

Use:

- readable monospaced timer digits
- clean project text
- optional restrained serif accent

The timer must always be the dominant element.

## Frame content

Each frame should show:

- overlay on a simple desktop-like background
- resting timer state
- project name below timer
- enough context to judge contrast and transparency

A small hover toolbar preview may be included inside the same frame.

Do not create extra screens.

## Construction rules

Before creating:

1. Inspect existing floating overlay designs.
2. Understand the product structure.
3. Create only the new dark Acanthus study section.

Use:
- editable Figma layers
- editable vectors

Do not:

## Quality checklist

Each concept must have:

- dominant timer
- project name below timer
- readable dark mode
- clear Acanthus identity
- restrained ornament
- unique visual direction
- realistic desktop overlay feeling
