# Nika's Chronicle artwork

Production files are embedded in both `StopwatchOverlay/Assets/Nika/` and `StopwatchOverlay.Desktop/Assets/Nika/`. No runtime access to Downloads or Codex image folders is required.

The corrected controller also embeds `navy-map.png`, a subdued cartographic texture for its header, sidebar and footer. The controller's heavy timer type uses a static Black instance of [Roboto Condensed from Google Fonts](https://github.com/google/fonts/tree/main/ofl/robotocondensed); its OFL license is included beside the font in each frontend's `Assets/Fonts/Nika/`. The static instance was created from the official variable font at weight 900 using fontTools; no system font installation is required.

The approved mural alternatives are preserved in `mural-atlas.png`. `NikaThemeCatalog.GetArtworkRegion` supplies normalized source rectangles that exclude the sheet's headings, captions and dividing rules. The default warrior now renders a decorative-only source rectangle from `approved-art-atlas.png`, a preserved copy of the approved panel reference. WPF uses a bounded CroppedBitmap at (23,550,350,338); Avalonia draws its explicit (23,550,350,345) source rectangle. Both exclude UI labels and controls. The earlier isolated `warrior.png` is retained as a source alternative; `log-pose.png` preserves its generated alpha channel.

The three standalone assets were created with the built-in imagegen tool on 2026-10-26, using `approved-controller-concept.png` as the visual reference and `sun-warrior-reference.jpg` as an additional pose reference for the warrior.
